# 網購記帳簿・獨立版（不經過 Claude）

這是一個完全獨立運作的網頁版 App，資料存在你手機瀏覽器本機，不需要 claude.ai 帳號，也不會經過 Claude。

## 檔案說明
- `index.html` — App 本體，打開這個檔案就能用
- `manifest.json`、`service-worker.js`、`icon-192.png`、`icon-512.png` — 讓它可以「新增到主畫面」變成類似 App 的圖示與離線功能
- `storage-shim.js` — 讓資料存到瀏覽器本機（localStorage）

## 怎麼開始用（最簡單）
1. 把整個資料夾（5 個檔案都要在同一層）上傳到你的 Google 雲端硬碟、或用免費的靜態網站空間（推薦 Netlify Drop：https://app.netlify.com/drop，把資料夾拖進去就會給你一個網址，完全免費、不用註冊帳號也能先試用）
2. 用手機瀏覽器（Chrome）打開那個網址
3. 瀏覽器選單 →「新增至主畫面」，桌面就會有一個圖示，之後點它開啟是全螢幕、離線也能用

也可以不上傳，直接把 `index.html` 存到手機、用瀏覽器開啟本機檔案來用——基本功能都正常，只是「新增到主畫面」在某些手機瀏覽器對本機檔案的支援比較不穩定，能上傳到一個網址還是比較穩。

## 設定截圖辨識 AI（選用，不設定也能用其他功能）
進 App 的「設定」→「截圖辨識 AI 設定」，依序有四層：

1. **Anthropic API 金鑰**（最準）
   - 到 https://console.anthropic.com 註冊，「API Keys」頁面建立一組新金鑰（新帳號通常有免費試用額度）
   - 貼到 App 裡的「Anthropic API 金鑰」欄位

2. **OpenAI（GPT）API 金鑰**（第二層備援）
   - 到 https://platform.openai.com/api-keys 註冊、建立一組新金鑰
   - 貼到 App 裡的「OpenAI（GPT）API 金鑰」欄位

3. **Gemini API 金鑰**（第三層備援，額度通常比較大方）
   - 到 https://aistudio.google.com/apikey 用 Google 帳號登入，免費建立一組金鑰
   - 貼到 App 裡的「Gemini API 金鑰」欄位

4. **本機文字辨識（Tesseract）**——完全免費、不用設定，前三層都沒設定或都失敗時會自動用這層，但準確度比較低，辨識完一定要自己檢查一下欄位對不對。

金鑰只會存在你這個瀏覽器裡，辨識時直接從你的手機送到對應官方伺服器，不會經過任何其他地方。

## 資料備份提醒
資料存在瀏覽器本機，換手機、換瀏覽器、清除瀏覽器資料都不會自動跟著走。建議定期到「設定」→「資料備份」匯出備份檔，存到你的雲端硬碟，之後要換裝置時匯入回來就能還原。

## 之後想再改功能怎麼辦
把改動需求告訴 Claude（在原本那個對話串裡說就可以），做完後我會給你新的 `index.html`，你只要把資料夾裡的 `index.html` 換成新的檔案（其他 4 個檔案不用動）就好，資料不會不見。
